# AutoHub Pro — Arabic user guide (PDF)

`AutoHub-Pro-User-Guide-AR.pdf` is the end-user guide in Arabic (RTL, A4) for dealership staff:
every page in the navigation, its buttons, fields and dialogs, the accounting effect of each money
operation in plain words, five step-by-step workflows, an FAQ / error-message table and the known
limits of the current release. All screenshots come from the running app with clearly fictional demo
data ("معرض الواحة للسيارات").

## Layout

| Path | What |
|---|---|
| `src/NN-*.html` | Guide content, one file per chapter (Arabic HTML fragments). `<shot id="x" caption="…">` inserts a screenshot; an `<ol class="co">` right after it explains the numbered callouts. |
| `images/*.jpg` | Screenshots (JPEG q80, 1440×900 desktop; 390 px phone shots at 2×). |
| `images/shots.json` | Size of each screenshot and the boxes of its numbered callouts (written by the capture). |
| `assets/fonts/` | IBM Plex Sans Arabic (the web app's font, from `@fontsource/ibm-plex-sans-arabic`, OFL). |
| `scripts/seed.mjs` | Seeds demo data into a fresh sandbox through the real API (resumable; state in `scripts/.seed-state.json`). |
| `scripts/shots.mjs` | The screenshot list (user, page, actions, crop, callouts). |
| `scripts/capture.mjs` | Takes the screenshots with Playwright (Arabic UI, light theme). |
| `scripts/build.mjs` | Builds `guide.html` and the PDF (cover + body, header/footer page numbers, TOC page numbers). |
| `guide.html` | The assembled HTML (open in a browser; images and fonts are relative). |

## Regenerate

From the repository root (PostgreSQL running, dependencies installed, `apps/api/.env` present):

```bash
# 1. Fresh sandbox on database autohub_test_e (DROPS that database). The relaxed rate limits let
#    the seed and the capture sign in as several users quickly.
AUTH_RATE_LIMIT_PER_MIN=500 RATE_LIMIT_PER_MIN=100000 EXPORT_RATE_LIMIT_PER_MIN=200 \
  scripts/dev-sandbox.sh start e 3105 5205

# 2. Demo data (delete docs/user-guide/scripts/.seed-state.json first when the sandbox was reset)
node docs/user-guide/scripts/seed.mjs

# 3. Screenshots (all, or only ids starting with the given prefixes, e.g. `sale- veh-`)
node docs/user-guide/scripts/capture.mjs

# 4. HTML + PDF
node docs/user-guide/scripts/build.mjs

scripts/dev-sandbox.sh stop e
```

Requirements: Node 22, the Playwright package in `e2e/node_modules`, Chromium at
`/opt/pw-browsers/chromium-1194/chrome-linux/chrome` (override with `GUIDE_CHROME`), and `psql`,
`pdfinfo`, `pdftotext`, `pdfunite` (poppler-utils). The web URL defaults to `http://localhost:5205`
(`GUIDE_WEB_URL`).

Notes:

- The seed uses only the public API, with one exception: the API stamps `vehicles.stocked_at` with the
  real creation time, so the last seed step back-dates it to each purchase date with `psql` (sandbox
  only) so that "days in stock" and the aging screens show realistic values.
- Business dates in the seed are relative to the day it runs, so numbers and dates in the screenshots
  change slightly from one regeneration to the next.
- The demo car pictures are drawn illustrations generated by `scripts/demo-photos.mjs` and labelled
  as such.
- When the UI text changes, update the chapter text in `src/` (names of pages and buttons must match
  `apps/web/src/i18n/*.ts`) and the button names used in `scripts/shots.mjs`.
